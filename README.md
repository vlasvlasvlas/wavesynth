# WaveSynth 🌊🏄‍♂️🎹

> **Oceanographic Wavetable & Surfing Audio Interface**

Sintetizador interactivo en tiempo real que convierte la telemetría marina del planeta (altura de olas, período, viento, swell) en osciladores de audio, permitiendo "surfear" visualmente la forma de onda tridimensional en shaders y moldear armónicos con una tabla de surf interactiva.
